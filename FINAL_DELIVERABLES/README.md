# ISAPC Virgo α/Fe Analysis — Results & Reproducibility

This package organizes key outputs and a short report of the ISAPC workflow applied to the Virgo Cluster sample. It includes example fit plots, α/Fe (AIP) outputs, a cluster-level gradient figure, and summary tables. Links point to files staged under `FINAL_DELIVERABLES`.

## What’s included

- examples/
  - fitting/
    - VCC1588/: emission-reduced normalized spectrum examples (post-fit)
    - VCC1146/: emission-reduced normalized spectrum examples (post-fit)
  - aip/
    - VCC1588/: α/Fe 2D map and radial profile
    - VCC1146/: α/Fe 2D map and radial profile
- cluster/
  - virgo_cluster_final_gradients.png: cluster scatter with RDB α/Fe gradients, color-coded by velocity
- tables/
  - combined_gradient_summary.csv: per-galaxy α/Fe gradients (RDB 3-bin) and stats
  - run_summary.csv: per-galaxy pipeline status and normalized-spectra counts

## Method summary

1) ISAPC spectral fitting (P2P/VNB/RDB)
   - Stellar+gas decomposition via pPXF. Emission is modeled and subtracted.
   - We export emission-reduced, normalized spectra after the fit per spaxel (P2P), for QA.

2) AIP α/Fe estimation
   - Uses TMB03 index grid (Hβ, Mgb, Fe5015) and Phy_Visu helpers to derive α/Fe per valid pixel.
   - Saves 2D α/Fe map and RDB-based radial profile. Placeholder maps are created if indices are invalid.

3) Gradients and cluster visualization
   - RDB radial profiles are fit with three-bin slope (dex per Re) and compared across galaxies.
   - `virgo_cluster_final_gradients.png` places galaxies at sky coordinates and colors by velocity.

## Reproduce core artifacts

- Combined gradients CSV
  - Generated by `alpha_gradient_dual/build_combined_gradient_summary.py`
- Cluster figure
  - Generated by `create_virgo_cluster_final_corrected.py` reading the combined CSV
- AIP outputs per galaxy
  - Generated by `run_aip_alpha_fe.py --galaxy <VCC####>`

Note: VNB profiles are currently omitted in the combined CSV due to missing `bin_distances` in stored NPZ; RDB is complete. We can extend the loader if desired.

## Validation notes

- Emission-reduced normalized spectra exist (4 per galaxy typically) and were verified in `run_summary.csv`.
- Example galaxies VCC1588 and VCC1146 are included with both normalized spectra and AIP plots.
- Threading is pinned (BLAS=4, n_jobs=4) for consistent performance.
- Redshifts used in plots are centralized and consistent across modes.
